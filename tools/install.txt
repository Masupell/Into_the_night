Elevation, moisture and star data (not tracked by git), all commands from the project root.
The game crashes without data/earth_tiles.bin, so this is necessary.

1. Python environment for the tools
python3 -m venv tools/.venv && tools/.venv/bin/pip install -r tools/requirements.txt

2. Download ETOPO 2022 surface elevation, 30 arc seconds, GeoTIFF (1.6 GB) into data/source/
https://www.ngdc.noaa.gov/mgg/global/relief/ETOPO2022/data/30s/30s_surface_elev_gtif/ETOPO_2022_v1_30s_N90W180_surface.tif
mkdir -p data/source && curl -L -o data/source/ETOPO_2022_v1_30s_N90W180_surface.tif <url above>

3. Convert to raw int16 meters (data/etopo_30s.bin, 1.9 GB, needs ~13 GB RAM)
tools/.venv/bin/python tools/convert_etopo.py data/source/ETOPO_2022_v1_30s_N90W180_surface.tif data/etopo_30s

4. Bake the tile pyramid the game streams from (data/earth_tiles.bin, 4.4 GB)
tools/.venv/bin/python tools/bake_tiles.py data/etopo_30s data/earth_tiles --max-level 7

5. Download the Global Aridity Index v3.1 (annual, 646 MB zip) into data/source/ and unpack the aridity map
Zomer, R. J.; Trabucco, A. (2022/2025): Global Aridity Index and Potential Evapotranspiration (ET0) Database v3.1,
https://doi.org/10.6084/m9.figshare.7504448, license CC BY 4.0 (the game has to credit it)
curl -L -o data/source/Global-AI_ET0__annual_v3_1.zip https://ndownloader.figshare.com/files/56300327
unzip -j data/source/Global-AI_ET0__annual_v3_1.zip 'Global-AI_ET0__annual_v3_1/ai_v31_yr.tif' -d data/source

6. Convert to moisture (data/moisture_60s.bin, 233 MB, needs ~12 GB RAM, ~30 s)
tools/.venv/bin/python tools/convert_aridity.py data/source/ai_v31_yr.tif data/moisture_60s --downsample 2

7. Bake the moisture tiles (data/earth_moisture.bin, 0.14 GB, ~15 s). --max-level must be the same as in step 4,
--tile-size must be TerrainTile.MOISTURE_SIZE. Without this file the game runs, but everything has plain grass
tools/.venv/bin/python tools/bake_tiles.py data/moisture_60s data/earth_moisture --max-level 7 --tile-size 33

8. Download the star map (NASA SVS Deep Star Maps 2020, 4k EXR, 36 MB) into data/source/. Without it the sky is black
Credit: NASA/Goddard Space Flight Center Scientific Visualization Studio, Gaia DR2: ESA/Gaia/DPAC, https://svs.gsfc.nasa.gov/4851
curl -L -o data/source/starmap_2020_4k.exr https://svs.gsfc.nasa.gov/vis/a000000/a004800/a004851/starmap_2020_4k.exr

Afterwards data/source/ (except the star map), data/etopo_30s.bin and data/moisture_60s.bin are only needed to bake again.
Smaller/older alternative: the 60s file (60s_surface_elev_gtif, 0.5 GB) with --max-level 6 gives a 1.1 GB earth_tiles.bin
